# XXD Panel 075 オリジナルスタイル指示 · 日本語参考訳

アップロードした各写真を、それぞれ独立した上質なデザインポスターにしてください。複数写真を組み合わせず、写真ごとに一枚ずつ出力します。全体は3:4の縦位置で、上下二領域の高さを厳密に1:1、各50%とします。

上部には元写真を残し、主体の同一性、構造、姿勢、実在感、自然な光と影、元の色彩の空気を維持します。ごく軽い上質なカラー調整だけを施し、アート誌、インディペンデント出版物、展覧会写真の質感にします。画面比率への適合には周囲の環境を自然に拡張できますが、主体を引き伸ばしたり、歪めたり、変更したりしないでください。

下部では、写真で最も識別性の高い**主体、輪郭、姿勢、物語上の関係**を抽出し、濃色クレヨンの速写感を持つミニマルな芸術画面へ再構成します。質感のあるアイボリーの手漉き紙を地にし、上の写真の総合的な色調と響き合う柔らかな不定形の色面を一つ加えます。低彩度の色をそっと広げたように、主体を支えつつ画面を埋め尽くさない色面です。写真を完全になぞらず、余計な物も加えません。ひと目で元の対象が分かる最小限の特徴だけを残し、省略、概括、描き止めの芸術性を保ちます。

主体は**簡潔な濃色クレヨン速写**で描き直します。線はゆるく自然で、わずかに不完全な筆致と軽い描き直しを含めます。細部はできるだけ簡略化しながら、重要な比率、方向、構造、姿勢は正確に保ちます。淡いリソグラフの粒子ノイズを加え、静かで懐かしく、控えめで触覚的な紙面の気配をつくります。

構図は精妙で抑制され、デザインとして練られたものにします。**視覚的重心、余白比率、主従階層、正負形、面のリズム、図と文字の呼応**を重視します。主体を機械的に中央へ置く必要はありません。元写真で最も心を動かす構造関係に応じて、中部またはやや下方に明確な着地点をつくります。不定形の色面、クレヨン線、文字の間に自然な牽引と呼吸を生み、静かに弛緩しながらも推敲された版面秩序を持たせます。大きな余白を保ち、空白そのものに感情、距離、時間を担わせます。参考構図をそのまま写さないでください。

文字はごく少量だけ介入させ、写真の主体、場所、感情、象徴性から短い英単語または短文を抽出します。**小さく抑制された、わずかな機械誤差を持つタイプライター書体**を使い、低い視覚ウェイト、広い余白、自然なずれで画面へ溶け込ませます。色面の近く、主体の縁沿い、大きな空白に置き、商業見出しではなくインディペンデント出版物の私的な注記のように扱います。

全体は静かで懐かしく抑制され、モランディ的な美意識と手工紙の触感を備えます。**濃色クレヨン速写、柔らかな色面、大きな余白、精妙な構図、繊細な組版**が一体となった上質な芸術性を目指します。写実的な精密描写、複雑な背景、太い漫画線、鮮やかすぎる差し色、過剰装飾、テンプレート的なポスター、安価なCG感は避けます。
